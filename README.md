# Student Management System

A responsive, polished landing page for a student management platform. Built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required.

## Homepage features

- Responsive navigation and layouts for mobile, tablet, and desktop.
- Interactive search for sections on the page.
- Light and dark themes, with the selected theme saved in the browser.
- A school dashboard preview, platform overview, feature cards, workflow, and calls to action.
- An informational school-portal access dialog.

## Project structure

- `index.html` — page content and accessible dialog markup.
- `assets/css/style.css` — responsive styles, visual components, and theme colors.
- `assets/js/script.js` — navigation, search, theme, and dialog interactions.
